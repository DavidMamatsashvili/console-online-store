# Console Online Store

**Console Online Store** is a C# .NET 8 console application simulating a full-featured e-commerce platform. It demonstrates **Entity Framework Core**, **SQL Server integration**, and asynchronous programming with **async/await**. The project provides a menu-driven console interface for user registration, product browsing, shopping cart management, and order processing.

---

## 🚀 Features

- **User Management**: Secure registration and login, role-based access (Admin/User).  
- **Product Catalog**: Browse products by category, manufacturer, and price.  
- **Shopping Cart**: Add, remove, and view products dynamically.  
- **Order & Payment System**: Place orders and handle payments with balance checks.  
- **Database Integration**: Fully functional SQL Server database using Entity Framework Core.  
- **Console Navigation**: Interactive menus for easy user experience.  
- **Layered Architecture**: Clear separation between Controllers → Services → Repositories → Models.  

---

## 🧱 Technologies

- C# and .NET 8  
- Entity Framework Core (EF Core)  
- SQL Server  
- Async/Await for asynchronous operations  
- Console-based UI  

---

## 🗂 Project Structure

- **Controllers/** – Handles user input and actions  
- **Services/** – Business logic and operations  
- **Repositories/** – Data access layer using EF Core  
- **Models/** – Database entities  
- **MenuCore/** – Console menu system  
- **Program.cs** – Entry point of the application
